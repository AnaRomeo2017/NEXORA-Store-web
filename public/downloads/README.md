# مجلد ملفات التحميل

ضع هنا مثبّت NEXORA Store ليُخدَم من الموقع مباشرة:

```
public/downloads/NEXORA-Store-Setup-0.1.0.exe
```

المصدر في هذا المستودع:

```
F:\smart-pos-erp\dist-installers\NEXORA-Store-Setup-0.1.0.exe   (~129 MB)
```

رابط الإنتاج (GitHub Release):

```
https://github.com/AnaRomeo2017/NEXORA-Store-web/releases/download/v0.1.0/NEXORA-Store-Setup-0.1.0.exe
```

أو ارفع المثبّت محلياً هنا أثناء التطوير، أو اضبط `.env.local`:

```
NEXT_PUBLIC_NEXORA_WINDOWS_URL=https://github.com/AnaRomeo2017/NEXORA-Store-web/releases/download/v0.1.0/NEXORA-Store-Setup-0.1.0.exe
```

> ملفات `.exe` و `.apk` مستثناة من Git (راجع `.gitignore`) لتجنّب رفع ملفات ضخمة.
