# مجلد ملفات التحميل

التحميل الرسمي يتم من Google Drive، وليس من هذا المجلد:

https://drive.google.com/drive/folders/1BQUU0AQekabEYbOz2W-Na-I0tSIRQM30

يمكن تغيير الرابط عبر `.env.local`:

```
NEXT_PUBLIC_NEXORA_WINDOWS_URL=https://drive.google.com/drive/folders/1BQUU0AQekabEYbOz2W-Na-I0tSIRQM30
```

> ملفات `.exe` و `.apk` مستثناة من Git (راجع `.gitignore`) لتجنّب رفع ملفات ضخمة.
